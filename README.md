# صفحتي التعريفية – مشروع HTML

## فكرة المشروع
إنشاء صفحة ويب تعريفية بسيطة باللغة العربية باستخدام HTML مع تنسيق CSS داخل الصفحة.

## أهداف المشروع
- تطبيق أساسيات HTML.
- تنظيم الصفحة باستخدام عناصر دلالية مثل `header` و`nav` و`main` و`section` و`footer`.
- استخدام الروابط والقوائم والعناوين والفقرات.
- إضافة تعليقات `Comment` توضح وظيفة أجزاء الكود.
- جعل الصفحة مناسبة للعرض على الهاتف والحاسوب.

## الملفات
- `index.html`: الملف الرئيسي الذي يحتوي على الصفحة وكود التنسيق.

## طريقة تشغيل المشروع
1. نزّل ملف المشروع.
2. افتح ملف `index.html` باستخدام متصفح الإنترنت.
3. ستظهر الصفحة التعريفية.

## ملاحظة
رابط البريد الإلكتروني في الصفحة تجريبي (`student@example.com`) ويمكن تغييره إلى بريد مناسب عند الحاجة.
